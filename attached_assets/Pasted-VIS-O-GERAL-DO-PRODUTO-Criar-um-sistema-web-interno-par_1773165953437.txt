VISÃO GERAL DO PRODUTO

Criar um sistema web interno para gestão completa de locação de máquinas, substituindo as planilhas atuais e centralizando:

obras

máquinas

operadores

horas trabalhadas

diesel

fretes

faturamento

fluxo de caixa

salários

rentabilidade por máquina

O sistema deverá permitir:

registrar serviços

controlar uso das máquinas

calcular custos

acompanhar lucro por obra

gerar relatórios financeiros

OBJETIVO DO PRODUTO

Resolver problemas atuais:

informações espalhadas em várias planilhas

risco de erro manual

dificuldade de visualizar lucro real

dificuldade de acompanhar máquinas

falta de histórico centralizado

O sistema deve permitir:

✔ gestão operacional
✔ gestão financeira
✔ controle de máquinas
✔ controle de operadores
✔ visão de lucratividade

DESIGN EXECUTION CONTRACT (OBRIGATÓRIO)

Toda interface do sistema deve seguir as regras:

1 Identidade

O sistema deve parecer:

SaaS profissional

moderno

premium

não parecer planilha transformada em site

2 Filosofia visual

Crafted over Assembled

Cada elemento deve ter:

bordas arredondadas

sombras suaves

espaçamento generoso

profundidade visual

3 Hierarquia

Interface deve usar:

títulos grandes

subtítulos claros

cards

separação por seções

Nunca layouts densos.

4 Profundidade

Interface não deve ser plana.

Usar:

shadow-sm

hover effects

backdrop blur

animações leves

5 Micro-interações

Todos elementos clicáveis devem ter:

hover
focus
transition

Exemplo:

transition-all duration-200 ease-out
